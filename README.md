# Benjamin Zsigri

**AI-Assisted Product Builder | AI Automation & Agent Workflow Specialist**

I'm the founder of [Tribloc](https://tribloc.co.uk). I turn business problems into working prototypes, automations and internal tools.

I define the requirements, system boundaries and acceptance criteria, direct AI coding agents such as Claude Code and Codex, and check the result through tests, review and documented limits. I have about one year of hands-on practice. I do not code independently: AI tools write most of the code, to my requirements and checks.

## What I work on

- **Prototypes and internal tools:** from a loosely defined business problem to a scoped, testable result with a clear handoff.
- **Automation and integration:** workflows across APIs and MCP tools, using Make, n8n and code-based components built with AI agents.
- **Agent workflows:** task scoping, isolated work areas, approval gates, review steps and failure handling.
- **Quality and cost control:** acceptance tests, evaluation metrics, explicit unknown states and usage-cost tracking.
